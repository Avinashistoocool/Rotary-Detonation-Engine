What this model means

This is a schematic reduced-order visualisation, not a CFD solver or a validated propulsion simulation. Every quantity is unitless; scene coordinates are drawing coordinates only.

Wave kinematics
Angular phase advances on one shared visual clock. Co-rotating waves have equal nominal separation. Counter-rotating waves are an illustrative interaction mode, not a claim of a stable physical solution.
Sector state
A passing front consumes the local fresh layer. Following a short normalized recovery delay, its height relaxes toward a fill target. A decaying pulse and angular front envelope generate the virtual signals.
Startup
Initiation, transient and settled visual states are presentation stages only. The interface marker does not depict any initiation method, hardware design or procedure.
Non-idealities
Incomplete mixing changes fill uniformity; parasitic combustion adds diffuse warm patches; leakage sends blue markers downstream; wall loss reduces local intensity; temporary wave-count changes disrupt visual timing. These are qualitative perturbations, not predictions.
Synchronization & controls
The 3D fronts, unrolled strip and probe signals consume the same model state. Wave speed adjusts the shared visual clock, not a physical detonation velocity. At zero the clock is held. Pause and reduced-motion preferences stop automatic motion.
Display conventions
Transparent and exploded hardware is a visualization aid. In exploded mode, flow remains in the chamber reference frame. All construction and operating details: TBD: set by reviewed design.
Runtime
PlayCanvas 2.5.0, MIT-licensed, loaded from an exact-version CDN URL with integrity checking. Geometry, shaders, particles and graphs are generated locally; no other network assets are used.
